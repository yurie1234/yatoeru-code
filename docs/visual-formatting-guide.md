## 初心者向けの書き方・視覚表現ルール

読者は前提知識のない初心者だと想定して書く。

- 専門用語・略語は、初めて使う箇所で必ずやさしく言い換える。例:「監理支援機関（＝実習生の受け入れを支援する団体）」のように、用語の直後に（＝やさしい説明）を入れる。
- 一文を短くする。硬い漢字表現・お役所的な言い回しは、日常的な言葉に置き換える。
- 抽象的な説明の後には、必ず具体例か数字を添える。

### 使ってよい視覚装飾（HTML）

本文はMarkdownで書くが、下記の5種類のHTMLブロックだけは直接埋め込んでよい。これ以外の生HTMLやinline styleは使わないこと。

1. **重要ポイント・注意点を目立たせる箱**
   ```html
   <div class="col-callout"><p class="col-callout__label">ここが大事</p><p>本文…</p></div>
   ```
   注意・警告レベルは `col-callout--warning`、期限や重大な不利益など強い警告は `col-callout--danger` をクラスに追加する。

2. **文中で覚えてほしい語句・数字の強調**（1記事に3〜6箇所程度、乱用しない）
   ```html
   <span class="col-highlight">180日</span>
   ```

3. **記事の核心となる数字・結論を大きく見せる**
   ```html
   <span class="col-big">180日</span>
   ```

4. **手順・時系列がある内容は図解風のステップリストにする**
   ```html
   <ol class="col-steps"><li>最初にやること</li><li>次にやること</li><li>最後にやること</li></ol>
   ```

5. **二つの条件・選択肢を対比する**
   ```html
   <div class="col-compare"><div><h4>Aの場合</h4><p>…</p></div><div><h4>Bの場合</h4><p>…</p></div></div>
   ```

### 使いすぎない

これらは「本当に重要な部分だけ」に使う。すべての段落を箱で囲んだり、番号リストを不必要に多用したりしない（AI特徴チェックリストが禁じている「テンプレ構造の多用」に反するため）。目安は1記事あたり `col-callout` 2〜4個、`col-steps` または `col-compare` は内容に手順・比較が実際にある場合のみ1個程度。地の文（段落・見出し）による説明を主体にしたうえで、そこに要所だけ視覚装飾を添える。
